# 分镜生成器使用说明

## 功能简介

分镜生成器是一个Web界面，允许用户输入剧本，系统会自动：
1. 解析剧本内容
2. 分析资源库中的已有资源
3. 优先匹配并使用资源库中的资源
4. 生成包含资源来源标注的文字分镜脚本

## 使用方法

### 1. 启动服务器

```bash
cd server
python app.py
```

服务器将在 `http://localhost:5000` 启动。

### 2. 打开Web界面

在浏览器中打开：
```
file:///path/to/anigen/web/storyboard-generator.html
```

或者如果服务器支持静态文件服务，访问：
```
http://localhost:5000/web/storyboard-generator.html
```

### 3. 输入剧本

在文本框中输入您的剧本内容。支持以下格式：

#### 格式1：结构化格式
```
场景1：神秘森林
时间：白天
地点：室外

主角小明：这里是什么地方？看起来好神秘。（惊讶）
主角小明：我要小心探索。（谨慎）

动作：主角环顾四周，小心翼翼地前进

场景2：森林深处
时间：白天

主角小明：前面好像有什么东西在发光！（兴奋）

动作：主角快速向前跑去
```

#### 格式2：简单对话格式
```
主角小明：这里是什么地方？
主角小明：我要小心探索。
```

### 4. 配置选项

- **剧本标题**（可选）：为您的剧本设置标题
- **优先使用资源库资源**：勾选后，系统会优先从资源库中匹配已有资源

### 5. 生成分镜

点击"生成分镜脚本"按钮，系统会：
1. 解析剧本内容
2. 从资源库中匹配资源（如果启用）
3. 生成分镜脚本
4. 显示匹配的资源列表
5. 显示完整的分镜脚本

### 6. 查看结果

生成的分镜脚本包含：
- **统计信息**：总镜头数、总时长、标题
- **镜头列表**：每个镜头的详细信息
  - 镜头编号和场景编号
  - 镜头类型和时长
  - 画面描述（包含资源来源标注）
  - 对话内容
  - 使用的资源列表（如果匹配到资源库资源）

### 7. 导出结果

- **复制JSON**：将分镜脚本复制到剪贴板
- **下载JSON**：下载分镜脚本为JSON文件

## 资源匹配说明

当启用"优先使用资源库资源"时，系统会：

1. **角色匹配**：根据角色名称、描述、风格等匹配资源库中的角色
2. **场景匹配**：根据场景类型、氛围、时间等匹配资源库中的场景
3. **道具匹配**：根据道具名称、类别等匹配资源库中的道具
4. **动作匹配**：根据动作类型匹配资源库中的动作

匹配的资源会在分镜描述中标注，格式如：
```
场景: 神秘森林（来自资源库） | 角色: 主角小明（来自资源库） | ...
```

## API端点

### POST /api/storyboard/generate

生成分镜脚本

**请求体：**
```json
{
  "script_text": "剧本文本内容",
  "title": "剧本标题（可选）",
  "prefer_existing_resources": true
}
```

**响应：**
```json
{
  "success": true,
  "data": {
    "title": "剧本标题",
    "storyboard": [...],
    "metadata": {...}
  },
  "message": "分镜脚本生成成功"
}
```

### POST /api/script/parse

解析剧本文本

**请求体：**
```json
{
  "script_text": "剧本文本内容",
  "title": "剧本标题（可选）"
}
```

### GET /api/resources/list

获取资源库中的资源列表

**查询参数：**
- `resource_type`: 资源类型（character, scene, prop, action）
- `keyword`: 关键词搜索

## 注意事项

1. 确保服务器已启动并运行在 `http://localhost:5000`
2. 如果资源库中没有匹配的资源，系统会使用原始描述生成分镜
3. 剧本格式支持灵活，系统会尝试自动识别场景、对话、动作等
4. 建议在生成分镜前先添加一些资源到资源库，以获得更好的匹配效果

## 故障排除

### 无法连接到服务器
- 检查服务器是否已启动
- 确认API_BASE_URL是否正确（默认：http://localhost:5000）

### 生成失败
- 检查剧本文本是否为空
- 查看浏览器控制台的错误信息
- 检查服务器日志

### 资源匹配不准确
- 确保资源库中有相关资源
- 尝试调整资源描述，使其更具体
- 检查资源标签是否正确设置
