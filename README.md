# AniGen - AI动画生成系统

## 项目简介

AniGen是一个端到端的AI动画生成系统，实现从文本剧本到完整动画的自动化生成流程。系统通过AI技术自动完成剧本分析、分镜生成和动画制作，大大降低了动画制作的门槛。

## 核心功能

1. **资源库管理**: 管理角色、道具、场景、动作等可重用资源，每个资源包含图片和详细说明信息
2. **剧本处理**: 解析和分析文本剧本，提取场景、角色、对话等结构化信息
3. **分镜生成**: 基于剧本自动生成详细的分镜脚本，包括镜头类型、画面描述、时长等
4. **动画生成**: 根据分镜脚本生成完整的动画视频

## 系统架构

```
剧本输入 → 剧本处理模块 → 分镜生成模块 → 动画生成模块 → 动画输出
```

## 快速开始

### 环境要求

- Python 3.10+
- 相关AI服务的API密钥

### 安装步骤

1. 克隆项目
2. 安装依赖: `pip install -r requirements.txt`
3. 配置环境变量（见配置说明）
4. 运行项目

## 配置说明

详细配置说明请参考 `PROJECT_RULES.md` 中的配置文件结构部分。

主要需要配置：
- OpenAI API密钥（用于剧本分析和分镜生成）
- 图像生成API密钥（用于生成画面）
- 视频生成API密钥（用于生成动画）
- 资源库目录（默认：./assets）

## 资源库模块

资源库模块提供了完整的资源管理功能，支持：

- **资源类型**: 角色、道具、场景、动作
- **资源管理**: 增删改查、搜索匹配
- **图片管理**: 自动管理资源图片的存储和路径
- **索引系统**: 基于JSON的轻量级索引

详细使用说明请参考 `src/assets/README.md`，示例代码请参考 `src/assets/example.py`。
